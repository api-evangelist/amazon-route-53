This technical guide explores four private connectivity patterns for AgentCore Gateway: MCP servers using Amazon VPC Lattice endpoints, REST APIs via private endpoints, Amazon API Gateway targets using VPC Link, and Lambda functions with VPC-enabled ENIs. The post covers managed and self-managed Lattice configurations, hybrid connectivity through Direct Connect and Site-to-Site VPN, and multi-VPC architectures that keep agentic AI workload traffic off the public internet.
