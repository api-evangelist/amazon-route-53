# Amazon Route 53

Amazon Route 53 is a highly available and scalable Domain Name System (DNS) web service that provides DNS routing, domain name registration, and health checking capabilities. Route 53 connects user requests to internet applications running on AWS or on-premises infrastructure, and can be used to route traffic based on latency, geolocation, geoproximity, and weighted round-robin policies. It also offers domain registration services, allowing you to purchase and manage domain names directly through the API.

## APIs

- **Amazon Route 53 API** - The Route 53 API provides DNS routing, domain registration, and health check management capabilities.
